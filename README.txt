복구본 안내
============

이 폴더는 확보된 원본 코드 5개를 기준으로 재구성한 웹페이지입니다.

포함:
- index.html
- style.css
- volume.js
- rsi.js
- signal.js
- atch_prediction.json

중요:
분석 JS 원본은 atch_stock_data.json을 fetch하도록 되어 있습니다.
현재 확보된 파일 목록에는 이 원본 주가 데이터가 없으므로 임의의 데이터를 생성하지 않았습니다.
기존 atch_stock_data.json을 이 폴더에 추가하면 RSI/종합신호/거래량 분석이 연결됩니다.
